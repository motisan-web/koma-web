# 変更ログ：テーマ保存バグ修正 (#I-006)

> 2026-06-21

---

## fix #I-006: テーマ設定がリロード後にリセットされる

### 原因

`api/timer.php` の `set_theme` アクションが switch 文内に配置されていたが、
switch の直前に「slot が 1〜20 の範囲であること」を必須とするバリデーションが存在する。

```php
// この分岐の後に switch が来るため、set_theme は必ずここで弾かれていた
if ($slot < 1 || $slot > SLOT_MAX) {
    api_error('slot must be 1–' . SLOT_MAX);
}
```

`set_theme` は slot を必要としないが、switch に入る前に 400 エラーで終了していたため、
config.json への保存が**一度も成功していなかった**。

見た目は `<html data-theme>` を PHP が出力するためトグル時に切り替わるが、
ページリロードでデフォルトの dark に戻っていた。

### 修正

- `api/timer.php`: `set_theme` の処理を slot バリデーションの**前**（`get_state` と同じ位置）に移動
- switch 内の古い `case 'set_theme':` を削除

```php
// 修正後の配置（slot チェックより前）
if ($action === 'set_theme') {
    $theme = ($req['theme'] ?? '') === 'light' ? 'light' : 'dark';
    $cfg   = load_config();
    $cfg['theme'] = $theme;
    save_config($cfg);
    api_ok(['theme' => $theme]);
}
```

### 変更ファイル

- `api/timer.php`: set_theme を slot バリデーション前に移動、switch 内の重複ケースを削除
