# 変更ログ：履歴表示エリアとコピー機能 (#F-001)

> 2026-06-21

---

## feat #F-001: タイマー画面下部に履歴表示 + 空きコマへのコピーボタン

### 概要

タイマー画面のコマグリッド下部に「履歴」セクションを追加。
過去14日間の完了コマ（内容またはプロジェクトIDが入力されているもの）を最大40件表示し、
各行の「コピー」ボタンで現在の空きコマ（先頭のidleスロット）に内容・プロジェクトIDをコピーできる。

---

### 変更ファイル

**`index.php`**
- PHPで過去14日分のセッションファイルをループして完了コマを収集（`$recentHistory`）
- 名前・project_idがどちらも空のコマは除外
- 日付の新しい順でソート、40件に切り詰め
- コマグリッド下部に `<div class="koma-history" id="koma-history-area">` を追加
  - 折りたたみトグルボタン（▼/▶）
  - テーブル形式で「日付 / コマ# / 内容 / プロジェクト / 時間 / コピーボタン」を表示
  - 各行に `data-name` と `data-project` 属性を付与
- `window.KOMA_CONFIG` に `recentHistory` を追加（将来のJS利用のため）

**`assets/js/timer.js`**
- `findFirstIdleSlot()`: `komaState` を先頭から走査し、最初の idle スロット番号を返す
- `copyHistoryEntry(name, projectId)`:
  - 空きスロットを特定
  - そのスロットの name/project 入力欄に値を挿入
  - `doUpdateMeta()` でサーバーへ保存
  - `scrollIntoView` で該当カードへスクロール
- `initHistoryEvents()`:
  - `#btn-history-toggle` クリックで `#koma-history-body` の表示/非表示を切り替え
  - `.btn-history-copy` 各ボタンにクリックイベントをバインド
  - コピー後2秒間「コピー済み」と表示してから「コピー」に戻す
- `DOMContentLoaded` に `initHistoryEvents()` を追加

**`assets/css/timer.css`**
- `.koma-history` / `.koma-history__toggle` / `.koma-history__body` / `.koma-history__table` などのスタイルを追加
- テーブル列ごとに `.koma-history__date` / `__slot` / `__name` / `__project` / `__time` クラスで色・幅を制御
- `--bg-card` / `--border` などCSSカスタムプロパティを使用 → ライトテーマ自動対応済み

---

### 仕様メモ

- 履歴の「コピー」は name と project_id の2フィールドのみをコピー（時間はコピーしない）
- 空きコマなしの場合はalertを表示
- 履歴セクションはデフォルトで開いた状態（非embed時のみ表示）
- embed.phpでは `$isEmbed = true` のため履歴エリアは非表示
