# 実績・実績の進捗・宝箱

ID: T-005

## 決めたこと
- 実績はサイドバーにアイコンと個数だけ並べ、マウスオーバー（フォーカス）で説明と次の条件を出す。見出しは「実績」だけにする。
- 今日の実績は 6 フルデイ / 8 オーバードライブ / 10 ハイパードライブ / 12 リミットブレイク。10・12 の名前は Claude の仮決め。
- 獲得済みの一覧とは別に「実績の進捗」を「○○獲得まで あと何コマ」と進捗バーの一覧で出し、獲得に近い順に並べる（プログレスを感じられるように）。
- 職人（プロジェクト別）は直近7日に触れていなければ表示しない。
- 宝箱はお知らせ欄に1つだけ出し、未開封の実績をまとめて受け取る。初回は過去分をまとめた大きな宝箱。

## 実装の判断
- 開封済みは「イベント id の一覧」として保存する。獲得数そのものは毎回データから判定し直すので、過去のコマを編集しても獲得数は正しく追従する（開封済み id が減ることはない）。
- 開封の API はクライアントから id を受け取らず、サーバーで判定し直した分をすべて開封済みにする。
- 保存先は `data/users/<id>_achievements.json` にして git 管理外にした。`moti.json` は git 管理なので、本番の開封状態を上書きしないため。
