# 変更ログ：100分に丸めるボタンが機能しない問題の修正

> 2026-06-21

---

## fix: 100分に丸めるボタンを押しても表示が変わらない

### 原因

`renderKoma()` 内の `elapsed` 計算が `liveElapsed(k)`（segments から算出）を使っていた。

`round_to_100min` API は `k.total_seconds` を書き換えるが segments は変更しない。
そのため丸め成功後も `elapsed` が旧値のままになり：
- 経過時間の表示が変わらない（例: 500分のまま）
- ボタン表示条件 `elapsed > CFG.maxDurationSec` が true のままでボタンが消えない
- ユーザーには「何も起きていない」ように見える

### 修正

完了済みコマ（`isDone(status)` が true）は `k.total_seconds` を直接使用するよう変更。
実行中・一時停止中コマは引き続き `liveElapsed(k)` でリアルタイム計算。

```js
// 変更後
const done    = isDone(status);
const elapsed = k ? (done ? (k.total_seconds ?? 0) : liveElapsed(k)) : 0;
```

### 動作

丸め後：
- `k.total_seconds = 6000`（100分）
- `elapsed = 6000`
- 経過時間表示 → `1:40:00`
- 超過表示 → `+20分超過`（koma_duration=80分との差）
- ボタン表示条件 → `6000 > 6000` = false → ボタン非表示

### 変更ファイル

- `assets/js/timer.js`: `renderKoma()` の elapsed 計算を完了済みコマは `total_seconds` 優先に変更
