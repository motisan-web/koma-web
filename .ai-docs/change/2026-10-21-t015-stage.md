# T-015 サイドバーに「ステージ」表示を追加し、実績「ステージクリア」を出す

ID: T-015
日付: 2026-10-21
バージョン: 1.6.0

## 判断・意図
- 週の目標（コマ数）を、数字の羅列ではなく「道を進む」絵で見せるため、ピクミン ブルームのステージ画面を参考にした。道の等分は稼働日の数（休みはカレンダー込み）に合わせ、1日の目標（週の目標 ÷ 稼働日）を超えた日に花が咲く。ミッションの「キノコ」は今日のコマに置き換えた。
- 報酬は既存の「ウィークリー30」と別物にした。ウィークリー30は週の合計が30コマなら偏っていても取れる。ステージクリアは「毎稼働日で目標を達成」なので、日ごとの継続を見る。実績の仕組み（イベント id と宝箱）に載せて、獲得の管理を流用した（id は `stage:<週の日曜>`）。
- ステージ番号は、最初にコマを記録した週を1とする通し番号にした（年の週番号だと年をまたいで飛ぶため）。
- 達成の判定は PHP（実績）と JS（その場の表示）の両方にある。表示は今日の分が毎秒変わるので JS に持たせ、実績は過去の週まで遡るので PHP に持たせた。
- 過去の週も今の設定（目標・休みの曜日・カレンダーの例外）で判定する。設定を変えると過去の獲得が増減するが、ウィークリー30と同じく「今の基準で数える」方針にそろえた。
- 稼働日が0の週は絵を出さず「ステージはお休み」の一文だけにする（ゼロ除算を避ける）。
- キャラクターは仮画像（SVG）。差し替えは `assets/img/stage-char.svg` を置き換えるか、`renderStage()` の `<image>` の href を変える。
- 先にモック（`mock/stage.html`）で見た目を決めてから実装した。
