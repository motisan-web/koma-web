## fix #I-007 追加修正: データが入ったコマも非表示になる問題

### 原因

前回の修正（`slot_count` 保存）だけでは不十分だった。

`$maxExistingSlot` の除外条件が `status === 'idle' && empty(segments)` だったため、
**入力（name/project_id）があっても idle かつ segments 空のコマはすべて除外されていた。**

追加ボタンで作って入力だけして未開始のコマは常にこの条件に当てはまるため、
`slot_count` が何らかの理由で保存されていない場合や、`slot_count` を実装する前に作られたコマは
リロード後に必ず非表示になっていた。

### 修正

`$isPhantom` の判定条件を「完全に空のコマのみ除外」に変更。

```php
// 変更前
if (!($k['status'] === 'idle' && empty($k['segments']))) { ... }

// 変更後
$isPhantom = $k['status'] === 'idle'
    && empty($k['segments'])
    && empty($k['name'])
    && empty($k['project_id']);
if (!$isPhantom) { ... }
```

これにより：
- name か project_id にデータがある → 表示される ✓
- segments がある（開始済み・完了など）→ 表示される ✓
- status が idle 以外 → 表示される ✓
- 完全に空の phantom koma（ensure_koma の副作用で生まれた意図しないもの）→ 除外 ✓

`slot_count` は「追加直後で未入力のコマ」のバックアップとして引き続き機能。

### 変更ファイル

- `index.php`: `$maxExistingSlot` の phantom 除外条件を `name`・`project_id` も確認するよう変更
