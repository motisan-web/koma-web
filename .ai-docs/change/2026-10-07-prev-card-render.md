# 前日の未完了コマ（一時停止）の時間が出ない

ID: I-016

- 日をまたいでリロードすると、前日の未完了コマの経過・残り・%が 0:00:00 / - / 0% のままだった。
- 原因: `buildPrevCard()` がカードをページに入れる前に `renderPrevKoma()` を呼んでいた。`renderPrevKoma()` は要素を id で探すので何も見つからず、描かずに終わっていた。実行中のコマは毎秒描き直すので気づかず、一時停止中のコマだけ初期表示のまま残った。
- 直したこと: カードをページに入れたあとで `renderPrevKoma()` を呼ぶ。
