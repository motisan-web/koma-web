# コマデータのコピーボタン・silentコマ・バージョン管理

ID: なし（依頼ベースの小機能）

- サイドバーに今日・昨日・一昨日のマークダウンをコピーするボタンを追加。既存の `api/output.php` を使い回し、新しい API は作らない。
- 最終行にコマ数と silent コマ数を追記。Obsidian のデイリーノートの `koma_completed` / `koma_silent` へ転記しやすくするため。
  既存の「合計作業時間 N分(日付)」の形は崩さず、その後ろに足した（受け取り側が前方一致で読んでいても壊れない）。
- コマ数は Obsidian の「完了数と時間÷80の大きい方」ではなく、Web 側の `koma_value()` に統一した（トップ・統計と数字がそろうことを優先）。
- バージョンを 1.0.0 から管理する。旧フッターの `v2.0.0` は正式な管理ではなかったので廃止。`CHANGELOG.md` は `.htaccess` の `.md` 遮断で公開されない。
- タグの打ち方・版の上げ方は `specs/operations.md` の「リリース」。
