## fix #I-002: 昨日のコマを完了すると今日の完了数にカウントされる

- `api/timer.php` `complete` アクション:
  - `$target_date !== today_str()` の場合（過去日付コマ完了時）、`completed_at` を `now_iso()` ではなく最後のセグメントの `end` 時刻に設定
  - 一時停止済みコマはセグメントのend時刻が昨日付になるため、stats等での日付集計が正しい日付で記録される

## fix #I-003: 昨日の未完コマがあると今日の同スロットのkoma-cardが非表示になる

- `index.php`: 以下のslot-hiding条件を削除

```php
// 削除した行:
if (isset($prevIncompleteSlots[$slot]) && !isset($komaMap[$slot])) continue;
```

- 前日未完コマと今日の同スロットは別のカード領域（prev-incomplete-area と koma-grid）で表示するため、今日のグリッドは常に全スロットを描画する

## feat #I-004: 100分自動完了機能の廃止

- `api/timer.php` `get_state` アクション: `$k['total_seconds'] >= $max_duration` による `overtime_max` への自動ステータス遷移を削除
- `api/timer.php` `start` アクション: `$elapsed >= $max_duration` による開始拒否（"最大時間に達しています"エラー）を削除
- `api/timer.php` `notify_100min` アクション: 自動完了処理を削除し、hookの発火のみを残す
- `assets/js/timer.js` `tick()`: `elapsed >= CFG.maxDurationSec` による `notify_100min` 自動呼び出しブロックを削除

> 代替: #I-005 の「100分に丸める」ボタンで手動対処する設計に変更。

## feat #I-005: 完了コマを100分に丸めるボタン

- `api/timer.php`: `round_to_100min` アクションを追加
  - 完了済み（`completed` / `closed` / `auto_closed`）かつ `total_seconds > max_duration` のコマのみ対象
  - `total_seconds = max_duration`（6000秒）に設定し、`overtime_seconds` を再計算して保存
- `index.php`: PHPテンプレートカードに `btn-round-{slot}` ボタンを追加（初期 `display:none`）
- `assets/js/timer.js`:
  - `renderKoma()`: `done && elapsed > CFG.maxDurationSec` のときボタンを表示
  - `doRoundTo100min(slot)`: confirm確認後に `round_to_100min` APIを呼び、応答komaでstate更新
  - `buildKomaCard()`: 動的追加カードにもボタンを含むテンプレートへ追加
  - `bindEvents()` / `addKoma()`: ボタンへのclickイベントバインドを追加
- `assets/css/timer.css`: `.btn-round`（オレンジ枠ゴースト）、`.btn-theme`（ヘッダーテーマトグル）のスタイルを追加
