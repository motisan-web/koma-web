# 完了ボタン制御 + リセット機能追加

> 日付: 2026-04-29

## 問題

1. **idle 状態でも完了ボタンが押せた** — 開始前に誤って完了できてしまう
2. **誤完了したコマが消える** — `segments: []` のまま `completed` になった koma は prev_incomplete にも出ず、翌日以降どこにも表示されなくなる

## 修正内容

### `api/timer.php` — `reset` アクション追加

`segments` が空（未開始）の `completed` koma を `idle` に戻す専用アクション。
開始済み（segments あり）には適用不可（エラーを返す）。

### `index.php` — 完了ボタンの初期 disabled

PHP レンダリング時、`$status === 'idle'` の場合に `disabled` 属性を付与。
またリセット用の `btn-reset-{slot}` ボタン（初期 `display:none`）を追加。

### `assets/js/timer.js`

- `renderKoma()`:
  - `btnComplete.disabled = done || status === 'idle'` （idle では完了不可）
  - `isPhantom`（`completed` + `segments.length === 0`）のときだけリセットボタンを表示
- `doReset(slot)` 追加 — `reset` API を呼んで koma を idle に戻す
- `buildKomaCard()` に `btn-reset` ボタン追加（動的スロット用）
- `addKoma()` のイベントバインドに `btn-reset` 追加
- `bindEvents()` に `.btn-reset` の querySelectorAll バインド追加

### データ修正（既存 phantom koma の削除）

- `data/sessions/2026/04-28/data.json` — `id:3` (completed, segments:[]) を削除
- `data/sessions/2026/04-25/data.json` — `id:2` (completed, segments:[]) を削除

## 影響範囲

- idle 状態では完了ボタンが操作不能になる（開始→pause/resume→完了 の正規フローのみ）
- 誤って完了した koma（segments 空）はカード上に「リセット」ボタンが出る → クリックで idle に戻る
- 開始済みの koma は reset 不可（API がエラーを返す）
