# 閉じ忘れた「実行中」コマの自動中止が動いていなかった

ID: I-015

## 起きたこと
- 本番の 2026-06-01 コマ2 が「実行中」のまま残り、6/1 から今までの経過（約4か月）がその日のコマ数（2,294.2 コマ）として統計・実績・Lv に入っていた。

## 原因
- 自動中止（旧 `auto_close_old_komas()`）は API の `get_state` でだけ動く作りだったが、どの画面も `get_state` を呼んでいなかった。
- さらに対象が90日前までで、それより古いセッションは見ていなかった。
- 異常値（1000分以上）の判定が完了扱いのコマだけで、作業中のコマの経過は数えてしまっていた。

## 直したこと
- 自動中止を `includes/koma_stats.php` の `koma_auto_close_stale()` に移し、全期間を対象にして、トップ・統計の表示時にも走らせる。
- 異常値の判定を、作業中・一時停止中のコマにも「今までの経過」で当てはめる（自動中止より前でも数えない）。
- 実行中のまま放置したコマは、閉じた時点で1000分以上の異常値になる。経過を推測して丸めることはせず、これまでどおり統計の日別表示で本人が時間を直す（T-003 の方針）。
